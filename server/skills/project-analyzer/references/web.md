# Web 适配

从 package.json、构建配置、HTML/应用入口识别实际框架。Vue Router、文件路由、React Router 等按真实注册关系枚举页面，覆盖嵌套路由、动态路由及懒加载。路由参数不是多个固定页面；弹窗、布局、复用组件要与可导航页面区分。

沿模板/组件事件→状态管理或组合函数→请求封装→接口地址追踪。拼接地址、代理前缀和环境变量须有配置依据；不能凭同名函数把前端和后端连接。共享鉴权/客户端拦截器用所属 API scopes 隔离。

现有 demo、截图、文档用于解释 UI，但不自动等同当前运行页面。没有截图的路由保留 page 节点。只读分析不运行 package scripts、构建或启动开发服务器。
